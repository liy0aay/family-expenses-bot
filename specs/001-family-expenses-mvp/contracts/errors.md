# Ошибки домена → HTTP / тексты бота

Единый источник кодов. REST: один хелпер в `internal/adapter/rest` маппит ошибку домена в статус и тело `{error: {code, message}}` (контракт — `api/openapi.yaml`, схема `Error`). Бот: код ошибки — в тексты для пользователя; LLM получает `{error: {code, message}}` как результат тула.

| Ошибка домена | HTTP | code | Текст бота (пример) |
|---------------|------|------|---------------------|
| ErrInvalidAmount — сумма ≤ 0 или больше двух знаков после точки | 400 | `invalid_amount` | «Не понял сумму. Пример: 350 или 350.50 — не больше двух знаков после запятой.» |
| ErrInvalidCategory — не распознана категория | 400 | `invalid_category` | «Категория не из списка: еда, транспорт, жильё, развлечения, здоровье, покупки, другое.» |
| ErrInvalidDate — не разобрана дата/диапазон | 400 | `invalid_date` | «Не понял дату. Пример: вчера или 2026-10-15.» |
| ErrValidation — прочая ошибка данных (формат, длина комментария) | 400 | `bad_request` | «Проверь данные: <причина>.» |
| ErrNotFound — трата не найдена или чужая (изоляция, конституция I) | 404 | `not_found` | «Такой траты нет.» |
| ErrInternal — БД/неожиданная ошибка | 500 | `internal` | «Внутренняя ошибка, попробуй позже.» |

Вне домена (транспортные):

| Ситуация | Поведение |
|----------|-----------|
| LLM недоступна / таймаут / пустой финальный ответ | REST: 500 `internal`; бот: «Временная проблема с ИИ, попробуй чуть позже.» Данные не изменяются. |
| LLM не завершила ответ за лимит итераций цикла тулов | бот: «Не получилось обработать запрос. Попробуй упростить его или разбить на несколько сообщений.» Выполненные тулы не откатываются. |
| Ошибка валидации схемы запроса (ogen) | 400 `bad_request` (тот же хелпер формирует тело). |

Правила:

- Чужая трата и отсутствующая неразличимы (`not_found`) — не раскрываем существование чужих данных (FR-011).
- Тексты бота — короткие, по-русски, без slug и технических деталей (конституция IV).
- `message` в REST-ошибке — для логов/разработки; UI панели показывает свои формулировки по `code`.
